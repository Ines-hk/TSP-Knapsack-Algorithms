# TSP & Knapsack Algorithms Comparison

## Overview
Implementation and comparison of optimization algorithms for TSP and 0/1 Knapsack.

## Algorithms
- **TSP**: Greedy, Local Search (2-opt), Simulated Annealing, Genetic Algorithm
- **Knapsack**: Greedy, Local Search, Simulated Annealing (Standard & Subsets), Greedy Subsets

## Results
- TSP Greedy (large): 694.76
- TSP Genetic Algorithm (large): 842.77
- Knapsack Greedy (large): 2162

## Files
- `TSP_Knapsack_Algorithms_Comparison.ipynb` - Source code
- `all_algorithm_results.xlsx` - Execution results
